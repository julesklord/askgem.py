Installation

Python 3.10+ required. Install the latest stable build from PyPI:

# Using pip
$ pip install mentask

# Or from source
$ git clone https://github.com/pitahayaDevSoft/mentask.py
$ cd mentask.py && pip install -e .
# Run directly with a provider
$ mentask --provider gemini
$ mentask --provider openai --model gpt-4o
$ mentask --local # Ollama
$ mentask --cli codex # CLI Agent Bridge

CLI Agent Bridge: Use agent:codex, agent:opencode, agent:copilot, agent:devin, or agent:pi to delegate tasks to external CLI agents.

Technical Architecture

Modular architecture across four decoupled layers with strong provider abstraction.

┌─ COGNITIVE LAYER
│  └─ AgentOrchestrator
│     ├─ SessionManager (persistent memory, rollback)
│     ├─ ContextCompressor (proactive compaction)
│     └─ TaskClassifier (heuristic routing)
│
├─ PROVIDER LAYER (5 Engines)
│  ├─ GeminiProvider (Google GenAI SDK)
│  ├─ OpenAIProvider (OpenAI API)
│  ├─ OllamaProvider (local inference)
│  ├─ GemmaProvider (Gemma formatting)
│  └─ CLIProvider (agent bridge)
│
├─ TOOL ECOSYSTEM (20+ Tools)
│  ├─ Core: read_file, edit_file, execute_bash, grep_search
│  ├─ Web: web_search, web_fetch
│  ├─ Memory: working_memory, memory, rag_query
│  └─ MCP: community servers via stdio
│
├─ SECURITY LAYER
│  ├─ TrustManager (directory whitelist)
│  ├─ SecurityAnalyzer (command sanitization)
│  └─ SubprocessSafety (whitelisted commands)
│
└─ INFRASTRUCTURE
   ├─ RAG Manager (SQLite + TF-IDF)
   ├─ History Manager (JSON session files)
   └─ Config Manager (keyring + settings.json)

Provider Abstraction

BaseProvider → concrete implementations. Factory auto-detects from model ID, prefix, or installed CLI binary. Hot-swappable at runtime.

Changelog

v0.32.2 — CLI Agent Bridge

2026-07-12

  • Changed: CLI prefix renamed from cli: to agent: across all modules.
  • Changed: Removed gemini-cli, claude, aider from supported CLI agents. Added pi, copilot (GitHub Copilot CLI), and devin.
  • Changed: Status bar now shows the underlying CLI agent model (e.g., opencode / o3-pro).
  • Fixed: CLI argument order — subcommand now correctly precedes --model flag.
  • Fixed: Prompt header now includes ENGINE and MODEL lines so external agents know their identity.

v0.32.1 — Thinking Model Fix

2026-07-12

  • Fixed: Empty response handling for thinking-only models (e.g., gemma4) — thinking content now emitted as text.
  • Fixed: Guarded chunk["choices"][0] access to prevent IndexError on empty chunks.
  • Fixed: Orchestrator error events now handled gracefully in stream_response().

v0.32.0 — Security Hardening

2026-07-12

  • Added: Sandbox command validation against dangerous shell patterns (command substitution, /etc redirects, mkfs, dd).
  • Added: 6 new dev commands — /export, /git, /diff, /context, /retry, /config.
  • Added: Truncation detection for finish_reason: "length" with visual warning.
  • Changed: Routed 12+ direct subprocess calls through subprocess_safety.py.
  • Changed: Provider prompt panel now wraps text in selectable Panel for better UX.
